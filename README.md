# AI Object Detection using YOLOv8

A Computer Vision project that detects objects in images using YOLOv8 and provides an interactive web interface using Streamlit.

## Project Demo

The application allows users to upload an image and automatically detects objects with confidence scores.

## Features

- Real-time object detection
- Image upload through web interface
- Object classification
- Confidence score display
- YOLOv8 deep learning model
- Streamlit interactive application

## Technologies Used

- Python
- YOLOv8 (Ultralytics)
- OpenCV
- Streamlit
- Computer Vision
- Deep Learning

## How It Works

1. User uploads an image.
2. YOLOv8 model processes the image.
3. Objects are detected and classified.
4. Detection results are displayed with bounding boxes and confidence scores.

## Model

YOLOv8 Nano (`yolov8n.pt`) is used for fast object detection.
